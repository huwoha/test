# test

C++ 项目。

## 编译

需要 MinGW-w64 编译器，安装在 `C:/mingw64/`。

- **开发版（Debug）**：`Ctrl+Shift+B`（默认），编译快、带调试信息。
- **发布版（Release）**：`Ctrl+Shift+B` → 选择 `C/C++: 发布版编译 (Release)`，静态链接、开箱即用。

## 打包

一键打包：`Ctrl+Shift+B` → 选择 **📦 一键打包 (编译+压缩)**。

流程：先用发布版编译出独立 exe，再自动压缩成 `xxx_v1.0.zip`。压缩包可以直接发给对方，解压即用，无需安装任何依赖。
